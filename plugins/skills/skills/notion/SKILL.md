at the start of each session, even when Notion is not mentioned:

- **tkodev: career and work.** [Start Here](https://app.notion.com/p/4065414be3f8814b92baccd85cb746a5).
  Topics: professional background, career advice, job search, applications, resumes,
  interviews, recruiter chats, project/client work, compensation, work finances,
  corporate administration, ideation, business ideas, venture planning, and resale listings.

Select the matching Notion connection. Before giving advice or taking action, read
Start Here's Page directory and Agents section. Follow the relevant pages, reading
their directories, Agents sections or Agents child pages, and required context
before proceeding. Collapsible sections must be read too; a directory listing alone
does not replace reading the linked context.

If a task spans both workspaces, read both guides. If required context is
inaccessible, state what is missing and keep advice provisional. Keep the listings
and workflows in Notion.
